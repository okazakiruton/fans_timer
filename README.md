# ずっちタイマー

Twitch配信の休憩時間だけ画面に現れる、たまごっち風の育成ミニゲーム（OBS用オーバーレイ）。

視聴者のコメントをキーワード検出して、キャラが光ったり喜んだり眠ったりします。休憩時間内で卵→幼生→成体に進化します。

## 使い方（GitHub Pagesで公開する場合）

公開URL: https://okazakiruton.github.io/fans_timer/

1. このリポジトリの Settings → Pages で、公開元のブランチ（例: `main`）を指定して有効化
2. 上記のURLをOBSの「ブラウザ」ソースのURLに設定
3. アプリ内の「はじめに」パネルにある「OBS用URLをコピー」ボタンを押すと、`?obs=1` を付けたクリーンな表示用URL（例: `https://okazakiruton.github.io/fans_timer/?obs=1`）がそのままコピーされます。OBSのURL欄に貼り付けるだけで、ボタンやパネルの一切ない透過表示になります

## 使い方（ローカルで試す場合）

このフォルダをまるごとダウンロードし、`index.html` をブラウザで開いてください。

## 機能

- 休憩タイマー（円形の残り時間表示）
- Twitchチャットへの匿名・読み取り専用接続（配信者側の認証設定は不要）
- キーワードに応じた11種類の反応（光・ハート・ガーン・怒り・食べる・トイレ・笑う・寝る・ストレッチ・給水・特殊演出）
- キーワードのカスタム追加（画面下部のパネルから。ブラウザのlocalStorageに保存）
- 累計反応回数の記録（同ブラウザ内）

## 注意点

- Twitchの利用規約に沿って、投げ銭を誘導するような演出は入れていません
- チャット接続は匿名の読み取り専用です。書き込みは一切行いません
